# Generative Vision: Art and Science of Visual Synthesis

Course website — Johns Hopkins University, Fall 2026.

Advanced graduate-level special topics course in computer vision, focused on how
generative models make pictures and what they learn about the visual world along
the way.

- `index.html` — the entire site. Self-contained: no build step, no dependencies,
  no external requests.
- Served by GitHub Pages from the `main` branch, root folder.

## Editing

Open `index.html` and edit directly. The schedule is a plain `<table>`; presenter
names go in the `Presenters` column (look for `class="slot"`), and slide links
replace the `&mdash;` in the `Slides` column.

Commit and push to publish.
